# 全页面交互重设计

覆盖当前 13 个工作室、84 个注册工具入口，以及图片、PDF、时间等页面内部子流程。目录由 registry 生成；旧工作室和单工具链接仍兼容跳转。当前功能合理性与修正记录见 [feature-audit.md](feature-audit.md)。

## 共同设计决策

- Atelier 暖纸色、森林绿与清晰排版；工具目录支持全局准确搜索、深链、前后导航、历史返回、手机原生选择器。
- 内容页保留输入，操作与输出分区；复制、下载、暂存和继续处理靠近结果。
- 文件、媒体和 CAD 按导入、设置、预览、导出组织；耗时任务有进度和取消，当前参数使结果失效时禁止导出。
- 次要参数折叠；空状态、输入错误、运行失败和恢复分别说明。
- 使用显式渲染翻译，编辑器、代码输出和用户内容不做 DOM 遍历改写。
